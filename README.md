### Rodar o servidor php local

```Bash
# Configurado para abrir no localhost:8080.

./start.sh
```

### Rodar o servidor web local

```Bash
# Costuma abrir por padrão no localhost:5500.

./start-web.sh
```
_Necessário rodar os comandos no root dir_

_Não tem SSR, precisa recarregar a página para ver as mudanças aplicadas._
